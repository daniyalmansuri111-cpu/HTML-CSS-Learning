# 🚗 ApexDrive — Supercar Showcase

> **The art of performance. The future of automotive design.**

ApexDrive is a futuristic digital showroom for discovering premium supercars. It combines cinematic visuals, interactive vehicle exploration, and a polished responsive interface.

## 1. ✨ Project Overview

Explore a curated supercar experience with a premium dark aesthetic, dynamic visuals, and interactive vehicle information.

## 2. 🌐 Live Demo

**[🚀 Launch ApexDrive](https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/ApexDrive%20Supercar%20Showcase/)**

## 3. ⚡ Key Features

- 🏎️ Premium supercar showcase and vehicle cards
- 🎬 Cinematic video background
- 🌌 Futuristic dark interface with gradients and glass effects
- 🧊 3D hover and tilt interactions
- 🖱️ Smooth scrolling and motion effects
- 🔍 Interactive search and category filters
- ❤️ Favorite vehicles and comparison experience
- 📊 Vehicle performance statistics
- 🎯 Car-details modal
- 📱 Responsive layout for desktop, tablet, and mobile

## 4. 🛠️ Built With

| Technology | Purpose |
|---|---|
| HTML5 | Semantic page structure |
| CSS3 | Styling, layout, transitions, and responsive design |
| JavaScript | UI interactions and dynamic behaviour |
| Bootstrap 5 | Layout utilities and components |
| Tailwind CSS | Utility-first styling |
| Font Awesome | Interface icons |
| Google Fonts | Typography |

## 5. 🎨 Design Direction

ApexDrive uses a premium automotive visual language: deep dark surfaces, bold imagery, vibrant accents, cinematic backgrounds, and subtle motion. The interface is designed to feel like an exclusive online showroom.

## 6. 💻 Run Locally

1. Clone the repository:
