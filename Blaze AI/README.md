# 🔥 BLAZE AI

### AI-Powered Productivity Workspace

BLAZE AI is a modern, interactive productivity web application designed to help users manage tasks, focus sessions, goals, and AI-powered assistance from one beautiful workspace.

## 🚀 Live Demo

**[🔥 BLAZE AI — Live Demo](https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/Blaze%20AI/)**

## ✨ Features

* 🤖 Interactive AI Assistant
* ✅ Add, complete, reopen and delete tasks
* 🔍 Task filtering
* ⏱️ 25-minute Focus Timer
* 📊 Productivity analytics
* 🎯 Interactive goal tracking
* 🌙 Dark / Light mode
* 🔔 Dynamic toast notifications
* 📱 Fully responsive design
* 📂 Interactive navigation
* ✨ Smooth scroll animations
* 🎨 Modern gradient and glassmorphism effects
* 👤 Professional profile interface
* ⚡ Fast and lightweight frontend

## 🎨 Design

BLAZE AI uses a futuristic productivity-focused interface featuring:

* 🟣 Purple
* 🟠 Orange
* 🟢 Lime
* 🩷 Pink
* ⚫ Deep dark surfaces

The design combines modern SaaS aesthetics, glassmorphism, gradients, rounded cards, subtle animations and strong typography.

## 🧠 AI Assistant

The built-in BLAZE AI assistant provides an interactive chat experience where users can:

* Ask productivity questions
* Get planning suggestions
* Brainstorm ideas
* Receive task-management advice
* Interact with AI-style responses

## ✅ Task Management

Users can manage their daily tasks directly from the dashboard.

### Available actions

* Add new tasks
* Set task priority
* Mark tasks as completed
* Reopen completed tasks
* Delete tasks
* Filter between All, Pending and Completed tasks

## ⏱️ Focus Mode

BLAZE AI includes a built-in Pomodoro-style focus timer.

**Features:**

* 25-minute focus session
* Start / pause controls
* Reset timer
* Progress indicator
* Completion notification

## 🎯 Goal Tracking

Track progress toward personal goals with visual progress indicators.

Example goals include:

* Master Frontend Development
* Learn JavaScript
* Launch Portfolio

## 📊 Productivity Dashboard

The dashboard provides a quick overview of:

* Task count
* Focus streak
* Active goals
* Weekly productivity
* Focus score

## 🌙 Theme Support

Switch between:

**Dark Mode** 🌑
and
**Light Mode** ☀️

with a single click.

## 📱 Responsive Design

BLAZE AI is designed to work across:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📟 Tablet

The navigation, task interface, AI chat and dashboard automatically adapt to different screen sizes.
