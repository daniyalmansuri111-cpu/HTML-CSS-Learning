# Personal Profile Page

A simple and responsive personal profile webpage built using HTML and CSS.

## Features

- Personal profile section
- About Me section
- Skills list
- Education details
- Contact section
- Styled with CSS
- Hover effects on buttons and links

## Technologies Used

- HTML5
- CSS3

## Project Structure

```
Profile-page/
├── index.html
├── style.css
└── README.md
```

## Learning Goals

This project was created to practice:
- HTML page structure
- CSS styling
- Colors and fonts
- Margins and padding
- Borders and border-radius
- Hover effects
- Basic webpage layout
