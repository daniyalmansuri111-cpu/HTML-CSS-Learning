# My First Calculator 🧮

A simple calculator built with **HTML, CSS, and JavaScript** as a beginner project. This was made while learning HTML and CSS, and it's a great first project for practicing the basics of front-end web development.

## What it does

- Add, subtract, multiply, and divide numbers
- Clear the screen with the **C** button
- Shows the result when you press **=**

## Built with

- **HTML** – structure of the calculator (buttons, screen)
- **CSS** – styling (colors, layout, grid for the buttons)
- **JavaScript** – the logic that makes the buttons actually work

## How to run it

1. Download or clone this repository
2. Open `beginner-calculator.html` in any web browser (double-click the file)
3. Start calculating!

No installation or setup needed — it's a single HTML file that runs directly in the browser.

## Project structure

```
├── beginner-calculator.html   # everything (HTML + CSS + JS) in one file
└── README.md                  # this file
```

## What I learned building this

- How to use CSS Grid (`display: grid`) to lay out buttons evenly
- How to style buttons with `:hover` effects
- How to use `onclick` in HTML to run JavaScript functions
- How to grab and update page content with `document.getElementById`
- How JavaScript's `eval()` can evaluate a math expression written as text
