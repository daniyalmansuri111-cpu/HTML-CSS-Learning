# HTML Image Layout Assignment

## Overview
This project is a simple HTML and CSS assignment demonstrating image layouts using Flexbox. It consists of two tasks completed in a single HTML file with internal CSS.

## Task 1
- Display 5 images in a single row.
- Each image is placed inside its own `<div>`.
- Images are arranged using `display: flex`.

## Task 2
- Display 3 image sections.
- Each section contains:
  - An image on the left.
  - A heading and description on the right.
- Flexbox is used to align the image and text side by side.

## Technologies Used
- HTML5
- CSS3 (Internal CSS)

## Concepts Practiced
- HTML Structure
- `<div>` Elements
- `<img>` Tag
- Headings (`<h2>`, `<h3>`)
- Paragraph (`<p>`)
- Internal CSS
- `display: flex`
- `justify-content`
- `align-items`
- Borders
- Padding
