👟 Sneaker Product Card
A simple and modern Sneaker Product Card created using HTML and CSS.

## 🌐 Live Demo
👉 [View Live Website](https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/DAY-04/)

📌 What I Used
HTML
<div> — to create and organize different sections of the card
<img> — to display the sneaker image
<h2> — to display the product name
<p> — to display the product description
<button> — to create the Add to Cart button
CSS
display: flex — to center the product card
background-color — to set the page background
border-radius — to create rounded corners
box-shadow — to add a shadow around the card
padding — to create space inside the card
margin — to control spacing
font-size — to adjust text size
color — to style the text
width and height — to control element sizes

  🛠️ Languages Used
