# 💰 FinTrack — Personal Finance Dashboard

> **Understand your money. Visualise your progress.**

FinTrack is a modern personal-finance dashboard concept that presents balances, income, expenses, savings, and transaction activity through a polished dark interface.

## 1. ✨ Project Overview

A finance-inspired dashboard featuring visual summaries, interactive charts, and transaction-management interactions. Figures shown in the interface are sample/demo data unless connected to a real data source.

## 2. 🌐 Live Demo

**[📊 Open FinTrack Dashboard](https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/Finetracker/)**

## 3. ⚡ Key Features

- 📊 Financial overview and balance summary
- 💰 Income, expense, and savings indicators
- 📈 Cash-flow and spending-category charts
- 💳 Recent transaction history
- ➕ Add-transaction modal
- 🔔 Notification and search interfaces
- 👥 Finance team and connected-account sections
- 📱 Responsive desktop, tablet, and mobile layout
- 🎨 Dark dashboard UI with colourful accents

## 4. 🛠️ Built With

| Technology | Purpose |
|---|---|
| HTML5 | Dashboard structure |
| CSS3 | Layout, styling, and responsive behaviour |
| JavaScript | Dynamic interactions and transaction UI |
| Chart.js | Data visualisation |
| Font Awesome | Icons |
| Google Fonts | Typography |

## 5. 📊 Dashboard Modules

- **Overview:** balance, income, expenses, and savings indicators.
- **Analytics:** cash-flow and category-based visualisations.
- **Transactions:** recent activity and transaction details.
- **Quick actions:** add-transaction and notification interfaces.

## 6. 💳 Transaction Interaction

The interface supports entering transaction details such as name, amount, type, category, date, and status. New entries can be reflected in the recent-transactions area without refreshing the page.

## 7. 💻 Run Locally
