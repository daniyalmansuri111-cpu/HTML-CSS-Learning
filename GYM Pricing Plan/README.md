# 🏋️ Gym Membership Plans

A modern and responsive **Gym Membership Pricing Plans** webpage built using HTML and CSS.

The website features a gym-themed background, dark overlay, transparent pricing cards, hover effects, and three different membership plans.

## ✨ Features

- 🏋️ Full-screen gym background
- 🌑 Dark background overlay
- 💳 Three membership plans
- 🔥 Highlighted Most Popular plan
- ✨ Hover animations
- 📱 Responsive design
- 💜 Modern purple theme
- 🔘 Join Now buttons
- 🌐 Built without JavaScript

🎨 Design
The webpage uses a full-screen gym background image with a dark overlay to make the content easy to read.
The membership cards use a semi-transparent design so the background remains visible while keeping the pricing information clear.
The Pro plan is highlighted as the Most Popular membership.

📱 Responsive Design
The website is responsive and works across:
💻 Desktop
📱 Mobile
📟 Tablet
The pricing cards automatically adjust their layout based on the screen size.
