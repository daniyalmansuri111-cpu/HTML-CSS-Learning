# Learnify — Modern Learning Platform

## Live Demo
👉 https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/Learnify/

## Overview
Learnify is a polished, responsive e-learning platform frontend designed to feel like a real modern education product rather than a simple landing page. It combines course discovery, learning progress, saved courses, interactive course previews, search, category filtering, weekly goals and responsive navigation in one cohesive experience.

## Interactive Features
### Course Discovery
Search courses by title, category or level and instantly filter the catalog.

### Saved Courses
Click the heart on any course to save or remove it. Saved course state persists with localStorage.

### Course Preview
Open a course to see its category, level, rating, learner count and lesson preview. The Start Learning action provides an interactive enrollment response.

### Learning Dashboard
The My Learning section presents an in-progress course, completion percentage, remaining time, weekly goal and learning streak.

### Responsive Navigation
Desktop navigation transforms into a mobile menu on smaller screens.

## Design Direction
Learnify intentionally uses a **light, classic and modern editorial aesthetic**:
- Warm cream background
- Forest-green primary color
- Muted sage accents
- Warm gold details
- Serif display typography paired with a clean sans-serif UI font
- Rounded cards with restrained shadows
- Spacious layouts and strong visual hierarchy

The interface is inspired by modern learning-product patterns such as clear course discovery, measurable progress, instructor credibility and focused learning flows.

## How to Run Locally
1. Clone the repository.
2. Open the `Learnify` folder.
3. Open `index.html` in a browser.
4. No build step or package installation is required.
