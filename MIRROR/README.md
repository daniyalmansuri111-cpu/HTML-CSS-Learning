# MIRROR — Internet Time Machine

> An interactive frontend experience that lets you travel through the visual language of the web.

## Live Demo

**GitHub Pages:** https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/MIRROR/

## What it is

MIRROR is a self-contained frontend concept built around one idea: every era of the internet has a recognizable interface language. Select a year and the archive reconstructs a stylized browser experience for that period.

## Highlights

- Interactive 1995 → 2026 timeline
- Era-specific browser simulations
- Then-vs-now visual comparison
- Random era discovery
- Shuffleable archive notes
- Responsive layout for desktop, tablet and mobile
- Accessible semantic HTML and labeled interactive controls
- No backend, API key or build step required

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Manrope + DM Mono)
- GitHub Pages

## Run locally

Open `index.html` directly in a modern browser, or use any static web server.

Example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/MIRROR/`.

## Design principles

MIRROR intentionally uses a restrained editorial system: strong typography, generous spacing, subtle borders, responsive components and era-driven visual changes instead of heavy dependencies.

## Disclaimer

The archive is a creative visual interpretation for frontend practice, not a historical reproduction of specific websites.
