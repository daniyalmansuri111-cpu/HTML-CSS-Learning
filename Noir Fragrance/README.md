🖤 NOIRÉ — Modern Fragrance
✨ A cinematic fragrance landing page built around dark luxury, warm cream typography, atmospheric imagery, and smooth motion.


🌙 About the Project
NOIRÉ is a modern fragrance landing page designed to feel dark, elegant, intimate, and cinematic.
The website combines editorial typography, immersive visuals, subtle animations, and a luxury-inspired color palette to create a premium fragrance brand experience.

✨ Highlights
🖤 Dark luxury aesthetic
🌹 Atmospheric fragrance visuals
🎬 Smooth entrance and scroll animations
✨ Interactive visual elements
🎨 Warm cream and charcoal color palette
🔤 Elegant editorial typography
📱 Fully responsive design
⚡ Fast Vite development environment
🧩 Reusable React components
➡️ Lucide React icons
🎞️ Framer Motion animations

🎨 Design Direction

NOIRÉ follows a minimal dark-luxury visual direction.

🔤 Typography

Almarai
Used as the primary website font.

Instrument Serif

🧭 Website Experience
🏠 Hero

The opening experience introduces NOIRÉ with a cinematic luxury presentation.

🌹 Fragrance Story
The story section focuses on atmosphere, presence, memory, and the emotions associated with fragrance.

✨ Interactive Scents
Explore three different fragrance personalities:

🖤 OBSIDIAN — The Signature
🍷 VELVET — The Intimate
🌙 NOCTURNE — The After Dark
🌿 Fragrance Notes

Explore the different layers of each fragrance through an interactive visual presentation.

🎬 Cinematic World
A full-screen atmospheric video section creates a strong visual transition between sections.

💎 The Collection
A dedicated product section presents the NOIRÉ bottle with product information and an interactive selection drawer.

📱 Responsive Design
The landing page is designed for:

📱 Mobile
📲 Tablet
💻 Laptop
🖥️ Desktop
🖥️ Large screens

The layout adapts typography, spacing, cards, navigation, and content for different screen sizes.
