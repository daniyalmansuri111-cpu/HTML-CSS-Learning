# 🖤 NOIRÉ — Modern Fragrance
A cinematic and immersive luxury fragrance landing page designed to showcase **NOIRÉ**, a modern fragrance brand focused on atmosphere, confidence, and unforgettable presence.

## 🌐 Live Demo
✨ [View NOIRÉ Fragrance Live Demo](https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/Noir-Fragrance/)

## ✨ Features

- 🖤 Dark luxury-inspired design
- 🌹 Cinematic fragrance presentation
- 🎬 Atmospheric video sections
- ✨ Interactive fragrance cards
- 💫 Smooth Framer Motion animations
- 🧴 Product-focused collection section
- 🌙 Elegant typography and visual effects
- 📱 Fully responsive design
- 🖱️ Interactive hover effects
- 🎨 Warm cream and charcoal color palette
- ⚡ Fast Vite development environment

## 🛠️ Tech Stack

- ⚛️ React 18
- 🔷 TypeScript
- ⚡ Vite
- 🎨 Tailwind CSS
- 🎬 Framer Motion
- ✨ Lucide React
- 🔤 Almarai
- 🖋️ Instrument Serif
- 🌐 GitHub Pages

## 🎨 Design

NOIRÉ follows a **dark, cinematic luxury aesthetic** using:

- 🖤 Black — `#000000`
- 🩶 Dark Charcoal — `#212121`
- 🌑 Deep Background — `#101010`
- 🕯️ Warm Cream — `#DEDBC8`
- 🤍 Primary Text — `#E1E0CC`

## 📱 Responsive Design

The website is designed to work smoothly across:

- 📱 Mobile
- 📲 Tablet
- 💻 Laptop
- 🖥️ Desktop
- 🖥️ Large screens
