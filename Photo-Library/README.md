# PHOTON — Photo Library 📸

PHOTON is a visual photo library designed around browsing rather than simply displaying a grid of images. It combines categories, search, favorites, a full-screen preview, and theme switching in a cinematic responsive interface.

## 2. Live Demo

## 1. What is PHOTON?

PHOTON turns a collection of photographs into a small interactive archive. You can explore different categories, search by name, save images as favorites, open photographs in a larger lightbox view, and switch between dark and light themes.

The project is completely frontend-based and does not need a backend.

## 3. Features

- Responsive photo gallery
- Nature, wildlife, people, and city collections
- Search the photo archive
- Filter images by category
- Save and remove favorites
- Favorites remain saved with browser localStorage
- Full-screen lightbox preview
- Keyboard Escape support for closing the preview
- Dark/light theme switching
- Curated collection buttons
- Lazy-loaded gallery images
- Responsive layout for desktop and mobile

## 4. Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Unsplash image URLs
- Browser localStorage
- GitHub Pages

## 5. How it works

The photo collection is defined in JavaScript. When you search or change a category, the gallery is rendered again with the matching images.

Favorites are stored locally in the browser, which means there is no account system or database behind the feature. The same approach is used for the selected theme.

Clicking a photograph opens it in the lightbox with its title and category.
