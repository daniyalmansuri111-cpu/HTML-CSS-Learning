# PHOTON — Futuristic Photo Library

A modern, artistic photo-library frontend built with **HTML, CSS and vanilla JavaScript**.

### ✦ Live Demo
https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/Photo-Library/

### Features
- Cinematic responsive masonry gallery
- Nature, wildlife, people and city collections
- Live search and category filters
- Favorites stored with localStorage
- Full-screen image lightbox
- Dark / light mode
- Responsive mobile layout
- Futuristic motion, editorial typography and neon-accent UI
- No framework required

### Run locally
Open `index.html` in a browser or serve the folder with any static server.

### Image sources
Demo images load remotely from Unsplash image URLs for this frontend concept.
