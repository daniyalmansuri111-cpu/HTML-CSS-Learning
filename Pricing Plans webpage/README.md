# 💳 Modern Pricing Cards

A modern and responsive pricing cards website built using **HTML5 and CSS3**. This project features three pricing plans with a clean dark-themed design, hover effects, and a responsive layout.

## ✨ Features

* Three pricing plans
* Basic, Pro, and Premium options
* Highlighted Most Popular plan
* Modern dark theme
* Gradient design
* Hover animations
* Responsive layout
* Mobile-friendly design
* Feature lists and pricing buttons

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* CSS Transitions
* CSS Gradients
