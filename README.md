## 💻 Run a Project Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/daniyalmansuri111-cpu/HTML-CSS-Learning.git
   ```
2. Open the project folder you want to explore.
3. Launch its `index.html` file in your browser. For projects that use local assets or browser features, use the VS Code **Live Server** extension.
