# 🍽️ Black Clover Restaurant

A simple and responsive **restaurant website** created using **HTML and CSS**. The website showcases the restaurant's homepage, about section, menu, contact information, and food items.

## 📌 Project Overview

**Black Clover Restaurant** is a front-end web development project designed to create a clean and attractive restaurant website.

The website includes:

* 🏠 Home section
* 📖 About Us section
* 🍛 Food Menu
* 📞 Contact section
* 🖼️ Restaurant and food images
* 📱 Responsive design for smaller screens

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **External Images** – Used for restaurant, logo, and food images

The project uses a separate `style.css` file for styling.

## ✨ Features

* Attractive red restaurant theme
* Navigation bar with Home, About, Menu and Contact links
* Hero section with a **View Menu** button
* Restaurant introduction section
* Food menu cards
* Hover effects on navigation links and menu items
* Responsive layout for mobile devices
* Restaurant logo integrated into the navigation bar

The CSS includes responsive behavior that changes the menu to a single-column layout on screens below 700px.
