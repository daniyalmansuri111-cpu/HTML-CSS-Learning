# Samsung S24 Interface 📱

This project is a browser-based recreation of a Samsung Galaxy S24-style mobile interface. It places a familiar mobile layout inside a phone frame and adds several interactive screens so the interface feels like a small working phone rather than a static design.

## 2. Live Demo

## 1. What is this project?

The project focuses on recreating the look and basic interactions of a modern Android phone interface using only HTML, CSS, and JavaScript.

From the home screen, you can open different apps, pull down the quick-settings panel, change brightness, toggle quick settings, and move between app screens.

## 3. What you can try

- Galaxy S24-inspired phone frame and home screen
- App grid and bottom dock
- Phone screen with keypad
- Messages screen with sample conversations
- Samsung Internet-style screen
- Camera interface
- Gallery interface
- Settings screen
- Working calculator-style keypad
- Calendar screen
- Quick Settings and notification shade
- Wi-Fi, Bluetooth, sound, flashlight, and other toggle states
- Brightness slider
- Live clock in the status bar
- Responsive presentation for different screen sizes

## 4. Built With

- HTML5
- CSS3
- Vanilla JavaScript
- SVG assets
- GitHub Pages

There is no framework, package installation, or build step required.

## 5. How the interface works

The phone starts on the home screen. Each app button is connected to a JavaScript interaction that opens the corresponding app view inside the phone.

The quick-settings panel works in a similar way. Its buttons can be toggled, while the brightness slider changes the brightness of the simulated phone screen.

This is a frontend interface concept and does not connect to an actual Samsung device or Android system.
