# Samsung S24 Interface

An interactive Samsung Galaxy S24-inspired mobile UI built with HTML, CSS and vanilla JavaScript.

## Live Demo

[Open the live demo](https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/Samsung%20S24%20Interface/)

## Features

- Galaxy S24-style phone frame and wallpaper
- Home screen with app grid and dock
- Quick Settings and notification shade
- Interactive Phone, Messages, Internet, Camera, Gallery, Settings, Calculator and Calendar screens
- Brightness slider and toggleable quick settings
- Responsive desktop/mobile presentation
- No framework or build step required

## Tech Stack

HTML5 · CSS3 · JavaScript

## Project Structure

- `index.html` — interface markup
- `style.css` — phone shell and app styling
- `script.js` — interactions and app screens

> Frontend concept inspired by Samsung One UI. It is not an official Samsung application.
