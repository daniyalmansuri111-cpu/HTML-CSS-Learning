# 🧠 Smart Quiz App

An interactive React quiz application featuring timed logic and brain-teaser questions, instant answer feedback, score tracking, and best-score persistence.

## ✨ Features

- 🧠 10 mind and logic questions
- ⏱️ 30-second timer per question
- ✅ Correct and incorrect answer feedback
- 📊 Score and percentage calculation
- 🏆 Best score saved in browser local storage
- 🔄 Restart quiz functionality
- 📱 Responsive interface
- ⚛️ Built with React + Vite
