# 🎓 Student Dashboard

A modern and responsive **Student Management Dashboard** built using **HTML, CSS, Bootstrap, and Tailwind CSS**.

This project was created as part of my web development learning journey to practice responsive layouts, UI design, Bootstrap components, Tailwind utility classes, CSS styling, and modern dashboard design.

## 🚀 Features

* 📊 Student dashboard overview
* 👤 Student profile section
* 📚 Course statistics
* 📈 Academic performance
* 🎯 CGPA display
* 📅 Today's class schedule
* 📝 Upcoming assignments
* 📊 Attendance percentage
* 🔔 Notification section
* 📱 Fully responsive design
* 📐 Responsive sidebar layout
* ✨ Hover effects and transitions
* 🎨 Modern dashboard UI

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Custom styling, animations, and responsive design
* **Bootstrap 5** — Responsive grid and UI components
* **Tailwind CSS** — Utility-based styling
* **Git & GitHub** — Version control and project hosting

## 🎨 Dashboard Sections

### 👤 Student Profile

Displays:

* Student profile picture
* Student name
* Course
* Semester
* Active student status

### 📊 Statistics

The dashboard contains cards for:

* Total Courses
* Attendance
* Current CGPA
* Assignments

### 📈 Academic Performance

Displays subject-wise performance using progress bars.

Subjects include:

* Web Development
* Java Programming
* Database Management
* Python
* Computer Networks

### 📝 Upcoming Assignments

Shows:

* Assignment title
* Subject
* Due date

### 📅 Today's Schedule

Displays:

* Class time
* Subject
* Room
* Professor

### 🔔 Notifications

Displays recent college notifications and updates.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Run it using **Live Server**.
5. The dashboard will open in your browser.

You can also open `index.html` directly in a browser.
