# 🌤️ SkyCast Weather

Responsive weather dashboard using HTML, CSS and vanilla JavaScript.

## Features
- Glassmorphism UI
- City search
- Celsius/Fahrenheit toggle
- Geolocation button
- Animated weather icon
- 5-day forecast
- Humidity, wind, visibility and UV data
- Refresh interaction

## Run
Open `index.html` in a browser.

> Demo weather data is bundled in JavaScript so no API key is required. Connect a weather API later for live conditions.
