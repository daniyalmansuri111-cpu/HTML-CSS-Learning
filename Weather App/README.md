# SkyCast Weather 🌤️

SkyCast is a simple weather dashboard built to make common weather information easy to check at a glance. It has a clean glass-style interface, city search, unit switching, location support, and a five-day forecast.

## 1. What is SkyCast?

The app opens with a weather view for Pune and lets you search for other cities. The interface updates the temperature, weather condition, humidity, wind, visibility, UV index, and forecast when a city is selected.

The project uses bundled demo weather data, so it works without an API key.

## 3. Features

- Search for supported cities and display their weather information
- Switch between Celsius and Fahrenheit
- Use the browser's location permission button
- Five-day forecast section
- Humidity, wind, visibility, and UV index information
- Weather icons and weather-based background images
- Refresh the current weather view
- Responsive layout for smaller screens
- No backend or API key required

## 4. How it works

SkyCast is intentionally lightweight. The weather information is stored in JavaScript and the page is updated dynamically when the user searches for a city or changes the temperature unit.

The background also changes according to the displayed weather condition, giving the dashboard a different feel for sunny, cloudy, rainy, or snowy weather.

## 5. Built With

## 6. Run Locally

No installation or build process is needed.

1. Open the Weather App folder.
2. Open index.html in a browser.

You can also serve the folder with any simple local web server.
