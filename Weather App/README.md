# 🌤️ SkyCast Weather

A polished responsive weather dashboard using **HTML, CSS and vanilla JavaScript**.

## 🚀 Live Demo

👉 **[View SkyCast Weather Live](https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/)**

## ✨ Features

- Glassmorphism responsive UI
- City search
- Celsius / Fahrenheit toggle
- Browser geolocation button
- Animated weather interface
- Five-day forecast
- Humidity, wind, visibility and UV details
- Refresh interaction
- Mobile-friendly design

## 🛠️ Tech Stack

HTML5 • CSS3 • Vanilla JavaScript • Browser Geolocation API

## ▶️ Run Locally

Open `index.html` in a browser.

> Demo weather data is bundled in JavaScript, so no API key is required. The project is deployed automatically to GitHub Pages when the Weather App files change.
