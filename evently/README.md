# 🎟️ Evently — Smart Event Discovery

> A polished, responsive frontend for discovering events, saving favourites, and building a personal event schedule.

## 🚀 Live Demo

**[Open Evently Live Demo](https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/)**

> GitHub Pages uploads the `evently` folder as the deployed artifact, so `index.html` becomes the root of the live site. The site is therefore **not** served from `/evently/` in the deployed URL.

## ✨ Features

- 🔎 Instant event search
- 📍 Location filtering
- 🏷️ Category filtering
- ❤️ Save events to a personal schedule using `localStorage`
- 📋 Event detail modal
- 👤 Profile summary with saved-event count
- 🌙 Persistent dark/light mode
- 📱 Responsive mobile, tablet and desktop layouts
- 🖼️ High-quality remote event imagery
- 🎨 Professional editorial-style UI with smooth hover states and micro-interactions

## 🧰 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Manrope + DM Sans)
- Unsplash image CDN
- Browser `localStorage`

## ▶️ Run Locally

Open `evently/index.html` in a browser, or use the **Live Server** extension in VS Code for the best local development experience.

## 🌐 Deployment

Evently is deployed using GitHub Pages through `.github/workflows/evently-pages.yml`. The workflow uploads `./evently` as the Pages artifact, making `evently/index.html` the root `index.html` of the deployed website.

**Live URL:**

`https://daniyalmansuri111-cpu.github.io/HTML-CSS-Learning/`

## 🎯 Portfolio Highlights

Evently demonstrates practical frontend skills beyond static UI work: client-side state, persistent user preferences, filtering, search, modal interactions, responsive design, accessibility-minded controls, and polished visual hierarchy.

## 📝 Note

This is a frontend-only project. Event listings, profile information and saved schedules are demo data and are stored locally in the browser.
